# Upload this package to GitHub from Android

Target repository: https://github.com/bonifacemunala7/Bkomik-ludo-master1

1. Open the repository in Chrome and sign in to GitHub.
2. Open the repository's `main` branch.
3. Choose **Add file → Upload files**.
4. Extract `BKOMIK_Ludo_GitHub_Package.zip` on your phone first.
5. Upload the files and folders inside `BKOMIK_Ludo_GitHub_Package` (not the outer ZIP itself) to the repository root. Keep the `tests` folder and its file path.
6. Enter commit message: `Prepare BKOMIK Ludo Master source release`.
7. Commit directly to `main` if this is your first upload to the empty repository.
8. Refresh the repository and confirm `main.py`, `README.md`, `buildozer.spec`, `requirements.txt`, `tests/` and the release notes are visible.

Do not upload `stats.json`, signing keys, passwords, tokens, or private data. This package intentionally excludes them.
